## The one correction that reframes everything

**FIFAFAN50 is Airbnb's promo code, not ours.** It's entered at Airbnb checkout (`data/blog/airbnb-fifafan50-promo.mdx`), the booking happens on Airbnb, and Airbnb named it. We **cannot** rename it — the string customers type must match Airbnb's code exactly or redemption breaks.

That flips the trademark analysis the research assumed:

## Do's / Don'ts (tailored)

**DO**

1. Keep the code string exactly `FIFAFAN50` — it's Airbnb's; changing it breaks redemption.
2. Lead with Reels + comment-to-DM ("comment SOCCER") delivering the Airbnb deep link.
3. Over-explain the manual apply-at-checkout step (verify discount before finalizing) — that's the redemption killer on Airbnb.
4. Newsjack actual LA match days with geo-tags — legally safest, algorithmically strongest.

**DON'T**

1. Don't put FIFA/World Cup logos, trophy, mascot, or FIFA hashtags in _our_ posts — "summer of soccer" carries the same energy for free.
2. Don't post identical "50% off!" 21×; rotate the story around one code (offer fatigue spikes after 3 identical LTOs in 14 days).

4. Don't use the Boost button expecting bookings — use Ads Manager.
5. Don't let it die at redemption — have a July 22 rebook offer ready.
